# 🏥 Hospital Revenue and Appointment Dashboard | Excel

## 📌 Project Overview

The **Hospital Revenue and Appointment Dashboard** is an Excel-based data analytics project designed to explore hospital operations, revenue performance, billing activities, and appointment trends.

The project uses multiple datasets, including patients, doctors, appointments, treatments, and billing records, to organize healthcare information and present insights through interactive Excel dashboards and visualizations.

The objective is to transform raw hospital data into meaningful information that can support better business reporting and operational decision-making.

## 🎯 Project Objectives

- Analyze hospital revenue across different treatment types.
- Explore revenue distribution across hospital branches.
- Understand appointment trends and scheduling patterns.
- Examine patient appointment statuses, including scheduled, cancelled, and no-show appointments.
- Organize billing information and payment records.
- Present healthcare operational data through visual dashboards.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
- Dashboard Design

## 📊 Dataset Overview

The workbook contains the following datasets:

| Dataset | Description |
|---|---|
| Patients | Patient demographic and registration information |
| Doctors | Doctor details, specializations, and hospital branches |
| Appointments | Appointment dates, times, reasons, and statuses |
| Treatments | Treatment types, descriptions, costs, and dates |
| Billing | Billing amounts, payment methods, and payment statuses |

## 📈 Dashboard Features

- Hospital revenue analysis by treatment type.
- Revenue comparison across hospital branches.
- Appointment trend analysis.
- Appointment distribution by time.
- Appointment status analysis.
- Visual reporting using Excel charts and pivot tables.
